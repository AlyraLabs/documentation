title: Get a tracked transaction

---

Get one tracking record by Delora `transactionId`, source transaction hash, or destination transaction hash. Lookup is scoped to the integrator associated with `x-api-key`.

```bash
curl 'https://api.delora.build/v1/transactions/TRANSACTION_ID_OR_TX_HASH' \
  --header 'x-api-key: YOUR_API_KEY'
```

<Note>
`404` deliberately covers both unknown lookup keys and records outside your integrator scope. Delora does not reveal whether another integrator owns a transaction.
</Note>

The response uses the same transaction object returned by [List tracked transactions](/api-reference/endpoint/get-transactions). See [Transaction Tracking API](/api-reference/transaction-tracking/overview) for field and status semantics.
